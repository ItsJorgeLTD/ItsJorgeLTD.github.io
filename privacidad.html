Política de privacidad de ORIANA

ORIANA es una asistente personal de uso privado. Su único usuario es su propio dueño.

Datos de Google a los que accede

  • Gmail: lectura de correos, para buscarlos y responder preguntas sobre ellos. ORIANA no envía, borra ni modifica correos.
  • Google Calendar: lectura y escritura de eventos, para consultar disponibilidad y crear eventos y recordatorios.

Cómo se usan y se guardan

  • Los datos se usan solo para atender las peticiones del propio usuario.
  • Se procesan en un servidor privado del usuario, que no está expuesto a internet. Las credenciales de acceso se guardan en ese servidor.
  • Para generar respuestas, fragmentos del contenido pueden enviarse a proveedores de modelos de inteligencia artificial (Anthropic y OpenAI) bajo las cuentas del propio usuario.

Con quién se comparten

Con nadie más. Los datos no se venden, no se usan para publicidad y no se comparten con terceros.

Uso limitado

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.
